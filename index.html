Trust boundary

A QR code is only a container.

01 / Validate

Payload rules reject unsupported URL schemes, embedded URL credentials, invalid email inputs, and malformed Wi-Fi keys.

02 / Invalidate

Changing any input invalidates the previous export so Copy and Download cannot silently use stale data.

03 / Keep ephemeral

New payloads are never persisted to localStorage. A legacy history key is removed on load.

04 / Verify

QR generation does not prove that a destination is safe. Verify scanned URLs and actions independently.
